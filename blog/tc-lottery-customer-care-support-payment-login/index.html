Account Support

Use the support route visible in the live account

Public phone numbers, social profiles and forwarded contacts can become outdated or can belong to unrelated parties. For an account-specific issue, prefer the support, help or service option displayed inside the current TC Lottery account. That route can also reflect the platform’s current operating process.

TCGames.co.in is an independent information site and cannot open user accounts, see balances, reverse payments or approve withdrawals.

Account Support

For a login problem, describe the exact failure

State whether the account rejects the identifier, rejects the password, does not deliver an OTP, loops back to login or opens but then expires. Include the approximate time and device type, but do not include the actual password or OTP.

If the account already exists, do not register another one merely because login fails. Keep recovery attached to the original account.

Account Support

For a deposit problem, save both sides of the transaction

A useful payment record includes amount, time, platform order ID if shown, UPI or bank transaction reference, and the current wallet status. Mask the receiving account and your personal payment details before sharing a screenshot.

If money is debited but the wallet is pending, avoid paying the same order again until the first transaction has a final state.

Account Support

For a withdrawal problem, separate order status from bank receipt

First check whether the withdrawal order is pending, rejected, cancelled or marked completed. If it is marked completed but the bank or UPI account has not received the credit, save the payout reference shown by the platform and compare it with the receiving account.

A withdrawal-password error is different from a completed-but-not-received payout. Label the problem correctly so support does not have to guess which stage failed.

Account Support

Never share credentials or remote-control access

A support request should not require your login password, withdrawal password, OTP, card PIN, UPI PIN or remote-access code. Do not install a screen-control app because someone claims they need it to fix a wallet problem.

If a contact asks for a payment to “unlock” an existing withdrawal without a matching in-account notice, stop and verify through the live platform’s own support area.

Account Support

How to write a compact support message

Use one issue per request. Start with the masked account ID, state the exact feature, give the time, order or period reference, quote the error wording and explain the current status in one or two lines. Attach only the screenshot that proves that issue.

Keep a copy of the request and any ticket or reference number. If the status changes later, reply with the new status instead of starting several unrelated conversations.

Common questions

TC Lottery Customer Care questions

Can TCGames.co.in access my TC Lottery account?

No. It cannot view balances, credentials, transactions or change platform account settings.

Which TC Lottery customer-care number should I use?

Prefer the current support route shown inside the live account rather than an unverified public number.

Should support ask for my OTP or password?

Do not share login passwords, withdrawal passwords, OTPs, PINs or remote-access codes.

What should I send for a payment complaint?

Send the masked account ID, amount, time, platform order ID, payment reference and current wallet status.

Should I open multiple support tickets for the same issue?

Usually no. Keep one clear record and update the same request unless the platform tells you otherwise.
