Withdrawal status

Start with the exact withdrawal order, not the current wallet balance

A missing bank credit is easiest to investigate when one TC Lottery withdrawal is isolated from every other wallet movement. Open withdrawal history and note the order ID or withdrawal ID, submitted amount, submitted time, current status and the receiving method shown for that request. Do not use only the present wallet balance as evidence because later deposits, game activity or other withdrawals can change that number.

Then open the receiving bank or UPI account and search the same date range. Check both the normal transaction list and any pending or reversed entries. If the TC Lottery record says completed but the receiving account has no matching credit, save that mismatch as the main issue. Avoid changing the receiving account or making another withdrawal just to see whether a second one arrives.

Status meaning

Completed, processing, rejected and reversed are different cases

ProcessingKeep the original order ID and wait for the status to change or for the platform support route to review it.Do not submit repeated withdrawals for the same amount only because the first is still processing.
CompletedCheck the receiving account, completion time and payout reference if one is displayed.Do not assume the bank credit must be visible in the same second.

The exact labels can change with the live platform. Use the wording shown in your own account rather than forcing the case into a label from an old screenshot or social post.

Receiving account

Match the destination that was attached to that withdrawal

Before assuming a payout is missing, verify which bank account, UPI ID or other payout method was connected to the specific withdrawal. Users sometimes check a recently added account while an earlier order was sent to the previously saved destination. Compare the masked account details shown in withdrawal history with the receiving account you are checking.

If the masked destination is unfamiliar, stop and use the authenticated account-support option. Do not send full bank numbers, passwords, OTPs or payment PINs in an open message. The purpose of the check is to confirm the destination, not expose the credentials that protect it.

Payout reference

Save the payout reference when the completed record provides one

A completed withdrawal can show a payout reference, transaction number or another settlement identifier. Save it exactly as displayed together with the withdrawal order ID. These two references can represent different sides of the same event: the TC Lottery order identifies the wallet request, while the payout reference may help the receiving financial provider identify the transfer.

If no payout reference appears, do not invent one and do not reuse the reference from a different withdrawal. Save a screenshot that includes the completed status, order ID, amount and time with private information masked. That is more useful than a cropped image showing only the word “completed.”

Common mistakes

A second withdrawal can make the first problem harder to explain

When one payout is unresolved, sending a second amount creates a new order, a new timestamp and possibly a new payout reference. It does not prove where the first withdrawal went. Keep the original case isolated until its final state is clear.

Also avoid changing bank details while the disputed order is still being traced. New details may apply only to future withdrawals and can make screenshots confusing. If the current receiving account is wrong or inaccessible, record that fact and let the platform decide the next account-level step.

Related checks

Keep withdrawal, deposit and login problems in separate records

A deposit that was debited but not added to the wallet is not the same as a withdrawal that shows completed but never appears at the bank. Use the TC Lottery UPI payment pending article for deposit reconciliation and the deposit and withdrawal section for the stable wallet overview.

The TC Lottery account and withdrawal checks on the homepage keep the main account routes together. If account access itself fails while you are trying to inspect a payout, solve the login problem first so the withdrawal history remains tied to the correct account.

What to share

A useful withdrawal complaint is short and traceable

Include the withdrawal order ID, amount, request time, completed time, masked destination and payout reference if available. State clearly that the receiving account was checked and no matching credit was found. This gives support a specific event to investigate.

Do not include your password, OTP, UPI PIN, full card number or remote-access permission. TCGames.co.in cannot view private TC Lottery accounts or change withdrawal status; account-specific decisions belong to the support option available inside the live platform.

Reference mismatch

When the withdrawal order and payout reference do not line up

Do not assume every number shown around a withdrawal is the same identifier. The account may display a withdrawal order, a platform transaction number and a separate payout reference. Write each label beside its value. If support asks for the withdrawal ID, send the value specifically labelled as the withdrawal or order record rather than whichever long number appears first.

If a payout reference is attached to a different amount or time, stop before using it as evidence. Two withdrawals with the same amount on the same day can still be different transactions. Match the order ID, amount, submitted time and destination together. A reference that belongs to the wrong order can send both platform support and the receiving bank toward the wrong transfer.

Bank-side search

Check more than the notification screen

A missing phone notification does not always mean a credit is missing. Open the actual bank or UPI account transaction history and search the relevant date. Some credits can appear with a processor or settlement description that does not use the exact TC Lottery name. Compare amount, date, time and reference instead of relying only on the transaction description.

If the receiving account has filters, clear them before searching. A credit can be hidden when the history is filtered to debits, a different date or a specific payment method. Take a current screenshot only after checking the full transaction list, and mask unrelated balances or account numbers if the image will be shared.

Withdrawal questions

Common questions when TC Lottery says completed

Should I create another withdrawal if the first says completed but is not received?

No. First trace the completed order using its order ID, destination and payout reference. A second withdrawal creates a separate case and does not locate the first transfer.

What if the receiving bank account is correct but no credit appears?

Save the completed withdrawal record and payout reference if available, then use the live account-support route. A traceable payout reference can also be useful when speaking with the receiving financial provider.

What if TC Lottery shows completed but there is no payout reference?

Record the order ID, amount, completion time and masked destination. Do not invent a bank reference or copy one from another withdrawal.

Can TCGames.co.in check my withdrawal status?

No. This site cannot access private accounts, payout systems or bank records. It can only help organize the checks and records needed for the live platform or financial provider.

Should I share OTP or bank login details with support?

No. A withdrawal trace should be possible with transaction references and masked account details. Keep passwords, OTPs, PINs and full financial credentials private.
