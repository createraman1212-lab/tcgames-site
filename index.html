Account lifecycle

Keep registration, access and recovery separate

A new TC Lottery account moves through registration, mobile verification and first access. An existing account normally returns through Login. Recovery is used when the correct account exists but the password or registered mobile access is unavailable. These stages should not be mixed. Creating another account because a password was mistyped can introduce duplicate-number errors, conflicting wallet records or uncertainty about which credentials belong to which account.

After successful access, confirm the displayed account identifier before opening the wallet, offers or app-related settings. On a shared device, log out completely and remove saved credentials. When an account is restricted or identity verification appears, stop repeated submissions and use the channel displayed inside the platform; TCGames.co.in cannot make an account decision.

Avoid preventable errors

Common actions that create a second problem

Registering again after a login failure

An existing account should be recovered. A second registration can create duplicate-number messages, separate credentials and uncertainty about which wallet belongs to which user ID.

Requesting several OTPs

Each resend can replace the earlier timed code. Waiting for the displayed timer and using only the newest message keeps the verification sequence clear.

Installing an APK from a private message

A forwarded file removes the live source, version and size checks. Return to the current App option and record the file shown there instead.

Repeating a pending payment

The first transfer may still complete. Compare the platform and payment-provider records before making another transaction for the same purpose.

Treating an invite code as a bonus amount

Invitation code 2801498961 identifies registration source. Only a separate account-visible offer can state a reward and its conditions.

Sending private values to an outside helper

A password, OTP, remote-access code or payment secret can transfer control of the account. Keep all such values inside the live platform fields.
