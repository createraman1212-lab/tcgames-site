Privacy Policy

This policy describes data handling on TCGames.co.in. The external TC Lottery destination is a separate service with its own data practices.

1. Information this site receives

TCGames.co.in is a static information website. It does not provide account registration, login, payment or contact forms. Hosting and security systems may process ordinary request data such as IP address, browser type, requested page, date, time and security signals to deliver and protect the site.

2. Local website behavior

The navigation script changes the mobile menu state in the browser. It does not create an account, read TC Lottery credentials or store a user profile.

3. External TC Lottery destination

Login, Register and App buttons open an external domain. Information entered there is handled by that destination, not by TCGames.co.in. Review its current privacy information before entering personal or payment details.

4. Cookies and analytics

The published site files do not set an advertising or analytics cookie. A hosting provider may still use essential security or delivery mechanisms. If analytics or forms are added in the future, this policy should be updated before collection begins.

5. Retention and control

Security logs controlled by the hosting provider may be retained according to its operational settings. TCGames.co.in cannot retrieve, correct or delete an account held by the external TC Lottery platform.

6. Children and age restriction

This site is intended only for adults aged 18 or older where access is lawful. It is not designed to collect information from children.

7. Changes

Material changes to this page will be reflected by the updated date. Current page date: 18 July 2026.

8. Security and sensitive information

TCGames.co.in does not ask readers to submit a password, OTP, recovery code, identity document or payment credential. Users should enter private account information only on the external platform after checking its address. Ordinary web delivery cannot be guaranteed risk-free, so devices and browsers should remain updated and shared-device sessions should be closed.

9. Separate controller and support requests

The external TC Lottery destination determines what account information it requests, why it processes that information and how long it retains it. Questions about an external account, transaction, application or identity record must be directed to that service. This website cannot retrieve or export those records.

10. Policy scope

This policy applies only to pages delivered from TCGames.co.in. It does not cover another website reached through an external link, a payment provider selected by the user, an Android application obtained from the destination or a communication channel operated by another party.

11. User choices on this domain

Readers can use the informational pages without creating a profile on TCGames.co.in. Browser controls can remove locally stored site data, and users can leave without opening an external action link. Removing local browser data does not delete an account or transaction held by TC Lottery or a payment provider.
