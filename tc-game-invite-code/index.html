Purpose boundary

A registration source is not a gift-code promise

An invitation code tells the platform which source is connected to registration. It does not contain an amount, expiry date, eligible-account definition or wallet condition. A TC Lottery bonus or gift code must appear separately with its own complete terms.

Do not deposit because the invitation field is filled. After registration, check the actual account-offer area. If no offer is visible, the code alone is not evidence that a reward should be credited.

Offer evidence

Save the offer title, eligibility, claim window and wallet condition—not only the invitation code—when evaluating a promotion.

Keep stages separate

Invitation, mobile verification and account creation

The invitation code is only one part of registration. Mobile number accuracy, OTP delivery, password rules and consent fields have their own validation. Changing the invitation code will not solve an OTP delay, and requesting several OTPs will not correct an invitation rejection.

Code dispute

Capture enough information without exposing the account

Record the complete destination address with unrelated personal parameters masked, the invitation value shown before submission, the registration time and exact error or confirmation. If registration succeeds, keep the resulting account identifier. If a claimed offer is disputed, also record the separate offer terms and wallet status.

Never send the password, OTP, full mobile number or identity document merely to prove that the code was present. The external platform can inspect its own registration event; TCGames.co.in cannot see whether a source was credited or change the code after submission.

Avoid random replacements

Why switching codes creates uncertainty

A code copied from a comment, group message or unrelated page identifies a different source and may have unknown conditions. Replacing 2801498961 to bypass an error makes it harder to establish which code the account finally used. It can also expose the user to misleading reward claims.

If the supplied code is rejected twice from the exact address, stop and use the platform’s own support option. Describe the error rather than asking another person to register the account or handle the OTP on your behalf.

After account creation

Check the account, not the URL, for the result

Once registration succeeds, the account record and live promotion area become the relevant source. The old registration URL can still contain the code, but reopening it does not prove the code’s final state or create another entitlement.

Log in to the correct account, review any offer attached to it and read the separate claim and wallet conditions. Use the bonus page for offer interpretation and the login page for future access.

Site limitation

TCGames.co.in publishes the supplied code and explains its states. It cannot attribute registrations, add a code later or issue a reward.

Address integrity

Check the parameter after the page opens

Some browsers shorten the visible address bar, wrap a long URL or hide the part after the domain. Expand the address before concluding that the invitation parameter disappeared. The supplied link should retain invitationCode=2801498961 and regSourceFlag=1 before the destination application processes it.

Do not paste the address into an unrelated link-shortening service, because the result can hide where the user is being sent and can remove or alter parameters. Use the complete supplied address and then inspect the registration response.

Existing number

A prior account changes the correct action

If the mobile number already belongs to a TC Lottery account, an invitation code normally cannot turn that existing account into a new registration. A message such as already registered or already used should move the task to Login or recovery. Repeating registration can create confusion without changing the original account source.

For a disputed old account, record the masked number, existing user ID if known and the exact message. Do not share the OTP or ask another person to register the number on a different device.
